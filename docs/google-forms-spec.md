### 投稿方法を選ぶ

最初のページで「簡単入力」「Googleドキュメントの共有リンク」「Wordファイル（.docx）」「Excelファイル（.xlsx）」「PDFファイル（.pdf）」から1つ選ぶ。簡単入力では本文と任意の写真、Googleドキュメントでは共有リンク、Word / Excel / PDFでは添付ファイルを入力する。どの方法でも、その後に共通のタイトル・活動日・カテゴリ・隊・タグのページに進む。

### ファイルから投稿する（Word / Excel / PDF）

活動報告（簡単）に、任意のファイルアップロード質問を追加する。質問タイトルはGASの `FIELDS` と一致させる。

| 質問タイトル | ファイル形式 | 対応する拡張子 | 最大数 | 上限 |
|---|---|---|---|---|
| `Wordファイル` | ドキュメント | `.docx` | 1件 | 10 MB |
| `Excelファイル` | スプレッドシート | `.xlsx` | 1件 | 10 MB |
| `PDFファイル` | PDF | `.pdf` | 1件 | 10 MB |

Googleフォームの説明には、対応する拡張子のみ対応と記載する。1回の投稿で添付できるのはWord / Excel / PDFのうち1種類だけで、複数種類が同時に送られるとサーバーは `multiple_files`（400）で拒否する。

添付した回答では、フォームのタイトル・活動日・カテゴリ・隊・タグを使用し、記事の本文は添付ファイルから作る。変換できないファイルや画像を含む場合は記事を登録せず、WebhookのエラーをApps Scriptの実行ログで確認できる。

- **Word**: 本文と写真をWordから取り込む。
- **Excel**: 表示されているシートだけを表として取り込む。非表示のシート・行・列は取り込まない。シートが複数ある場合はシート名を見出しにする。
- **PDF**: 各ページを画像として表示し、抽出したテキストを「テキストで読む」に折りたたんで載せる。最大20ページまで。パスワード付きのPDFは取り込めない。

導入時は以下の順（サーバー → GAS → フォーム）で反映する。

1. Webサーバーで、アプリの実行ユーザーから LibreOffice の `soffice`（Writer と Calc）、poppler の `pdftoppm` / `pdftotext` / `pdfinfo`、日本語フォントを利用できるようにする。Linuxではディストリビューションの `libreoffice-writer`、`libreoffice-calc`、`poppler-utils` などを使用する（デプロイワークフローは、システムにない場合にこれらを実行ユーザーのホーム配下へ配置する）。10 MBのファイルはBase64化で約13.4 MBになるため、リバースプロキシがある場合は、このWebhookの許容サイズを確認する。
2. サーバーと記事のスタイルをデプロイする。スタイルのビルドは `npm run build`。
3. 稼働中の `コード.gs` に [GASサンプル](gas-webhook-code-v2.js) の `FIELDS.WORD_FILE` / `EXCEL_FILE` / `PDF_FILE`、`UPLOAD_KINDS`、`handleFormSubmit` 内の添付ファイル分岐と必須チェック、`buildFilePayloadFromData` を反映する。既存の `onFormSubmitActivity` トリガーとスクリプトプロパティを使用する。
4. フォームに「Wordファイル」「Excelファイル」「PDFファイル」欄を追加する。既存トリガーの実行ユーザーが、アップロードされたファイルをDriveで読み取れることを確認する。

## 統合フォーム: ホームページ投稿フォーム

お知らせと活動報告を1つのフォームで投稿できるようにしたフォーム。トリガーは `onFormSubmitActivity` を1つ設定する。GASは「投稿の種類」が `お知らせ` の回答を `NEWS`（`/api/news/webhook`）として送信し、`活動報告` の回答は `ACTIVITY`（`/api/activities/webhook`）として送信する。

### セクション構成

| セクション | 内容 | 次の遷移 |
|---|---|---|
| 1. 投稿の種類 | ラジオボタン（必須）。選択肢は `お知らせ` / `活動報告` | お知らせ → 「お知らせの共通項目」、活動報告 → 「活動報告の共通項目」 |
| お知らせの共通項目 | 下記の質問 | 「投稿方法」へ |
| 活動報告の共通項目 | タイトル・活動日・カテゴリ・隊・タグ（従来の活動報告と同じ） | 「投稿方法」へ |
| 投稿方法 | ラジオボタン。選択に応じて下記のセクションへ分岐 | 簡単入力 / Googleドキュメント / Wordファイル / Excelファイル / PDFファイル |
| 簡単入力 / Googleドキュメント / Wordファイル / Excelファイル / PDFファイル | 各投稿方法の入力欄 | いずれも「フォームを送信」で終了 |

質問タイトルはGASの `FIELDS`（`投稿の種類` = `POST_TYPE`、`重要なお知らせにする` = `IMPORTANT`）と完全一致させる。

### お知らせの共通項目

| 質問 | 形式 | 必須 | 選択肢・備考 |
|---|---|---|---|
| タイトル | 記述式 | 必須 | |
| カテゴリ | プルダウン | 必須 | お知らせ / イベント / 募集 / 広報 |
| 隊 | チェックボックス | 任意 | 団全体 / ビーバー隊 / カブ隊 / ボーイ隊 / ベンチャー隊 / ローバー隊 |
| 重要なお知らせにする | チェックボックス | 任意 | 選択肢は1つ: `重要なお知らせとして目立たせる`。チェックするとタグ `重要` が追加され、赤い「重要」バッジが表示される |
| タグ | 記述式 | 任意 | カンマ区切りで入力 |

カテゴリの色は `src/server/utils/template-helpers.js` のキーワード判定で決まる（イベント→緑、募集→オレンジ、広報→紫、それ以外→青）。

### 活動報告の共通項目

従来の活動報告と同じ（タイトル、活動日、カテゴリ、隊、タグ）。

### 添付ファイルの扱い

Word / Excel / PDFファイルは、お知らせでも活動報告でも同じ仕組みで取り込む。ペイロードのキー `docx` / `xlsx` / `pdf` にBase64で送られ、`/api/news/webhook` も `/api/activities/webhook` と同様に変換する（複数種類が同時に送られると `multiple_files` で400）。GAS側は `uploadKinds` の判定を投稿の種類によらず実行する。

### トリガー追加手順
1. Apps Script エディタを開く
2. 左メニュー「トリガー」（時計アイコン）
3. 「トリガーを追加」
4. 以下を設定:
   - 実行する関数: `onFormSubmitNews` または `onFormSubmitActivity`
   - イベントのソース: 「フォームから」
   - イベントの種類: 「フォーム送信時」
   - フォームを選択: 対象のフォームを選択
5. 保存
